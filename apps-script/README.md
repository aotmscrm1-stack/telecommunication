# AOTMS CRM - Google Apps Script

This folder contains `Code.gs` for Google Sheets live synchronization with AOTMS CRM.

## Setup Instructions:
1. Open your Google Spreadsheet (`1NK3yVkkKxAOjgTCL46nEaCl1zpOxnn1vCeTAY9nX2Jg`).
2. Navigate to **Extensions** > **Apps Script**.
3. Replace the existing content in `Code.gs` with the contents of [`Code.gs`](./Code.gs).
4. Click **Save** (💾).
5. Refresh the spreadsheet.
6. Use the **🚀 CRM Sync** menu to sync leads or activate 1-minute auto-sync.
